# agents

子代理的工程执行记录。一行一条，由 `memory\经验.py` 写进来，也可以手写。

规矩：

1. 只记两种：一次就成的、试过失败的。流水账不记。
2. 失败条目必须写「死因：」——为什么不行，比「不行」值钱一百倍。
3. 位置写 `file:line`，不贴代码原文。
4. 满 30 条就把最老的十条压成一句，挪进 `压缩.md`。

派活门槛（主脑自检）：

- 要扫 3 个以上文件、或要读整个目录、或要改 3 个以上文件 → 派子代理，主脑只验收 diff。
- 单点读一个文件、改一行 → 自己动手，开一次比干一次还贵。
- 同一个坑第二次踩 → 说明这页没查，先查再派。
